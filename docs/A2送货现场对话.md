# A2 送货现场对话

## 操作

1. 从「送货」打开本趟待送达的客户单，点「对话改单」。
2. 发送「水饺实收三箱，单价 12.35 元」。可以分开发送「水饺实收三箱」「水饺补价 12.35 元」，也可以说「馄饨没收」。每次针对一条货品。遇到同名明细时，按品牌、规格和原单位点选对应行。
3. 核对实收和单价的变化、预计应收及待补价项，点「确认保存修改」。客户单有更新时，按最新明细重新发送并核对。
4. 发送「确认送达」或点「去确认送达」，页面滚到配送明细下方的「按实收数量确认送达」。配送员点该按钮后提交送达。实收数量大于零的明细需要先补齐单价。

对话按当前客户单解析文字，支持阿拉伯数字和常见中文数字。数量按正式单原单位修改。保存复用已有单行配送接口、正式版本、配送修订号和请求编号。待确认的改单在本次页面内显示，保存后重新读取客户单和取货汇总。
