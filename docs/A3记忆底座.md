# A3 上半场记忆底座

## 存储与账号隔离

迁移 `011_customer_aliases.sql` 新增 `dispatch.customer_aliases`，保留 `alias` 原文、`normalized_alias` 匹配键、`created_at` 和 `updated_at`。同一账号内 `(account_id, normalized_alias)` 唯一。当前基线的正式客户表为 `dispatch.parties`，简称表通过 `(account_id, customer_id)` 复合外键引用 `parties(account_id, id)`，对应正式客户及单据上的 `partyId`。

简称表启用并强制 RLS，查写范围由事务中的 `dispatch.account_id` 决定。`dispatch_app` 可读、增、删，也可更新关联客户、简称原文和修改时间。绑定和解绑复用工作区行锁与 `request_results`，相同请求重试返回首次成功结果，复用请求编号改参数返回 `request_conflict`。

## 业务规则

- **1A 历史来源。** 通过账号内正式客户单的 `sheets.party_id` 找到该客户的正式记录，取最新版本快照及对应行的现场改价和实收数。仅纳入正实收和正安全整数分单价。已核对的 `pending` 行需要现场实收才能参与。按首次正式出单时间倒序，精确到微秒，同时间按趟 ID 倒序、单 ID 正序、同单后出现的明细优先。主参考价附带最近一次不同成交价。
- **2A 同款匹配。** 货品、品牌、规格、单位统一折叠空白、全角 ASCII 与大小写，保留原文用于展示。货品和单位必须匹配。品牌与规格已填时严格筛选，缺项时按历史组合分为精确命中、唯一款、多个候选或无记录。
- **3A 草稿建议。** 工作区的草稿保存在 `dispatch.workspaces.draft_customers`。单条和批量查价走只读事务，缺价明细通过客户草稿 ID 与明细 ID 定位。已有单价跳过，缺少本账号正式客户 ID 的缺价行标为 `unresolved_customer`。
- **4A 熟客认人。** 正式大名与已记简称的精确命中按客户 ID 去重。唯一命中返回正式大名，精确撞名返回所有冲突客户；双字起的子串命中只提供候选。绑定默认拦截占用的简称和他店正式大名，分别用 `allowRebind: true` 与 `allowCanonicalConflict: true` 表示显式确认。解绑使用归一化后的简称定位记录。

## A3-2 调用接口

共用规则位于 [core/memory.ts](../code/miniprogram/core/memory.ts)。

- `normalizeMemoryText(value)` 返回匹配键。`resolveCustomerMention(directory, rawInput)` 返回 `resolved`、`ambiguous`、`candidate_only` 或 `new_customer`。后三种均携带 `customerId: null`，有候选时列出 ID 和正式大名。
- `suggestDraftCustomerMentions(customers, directory)` 为尚未选定客户且有称呼的草稿组返回认人建议。`mergeDraftCustomers(customers, directory)` 返回按正式客户 ID 合并的客户组，保留首组 ID 和各明细 ID，沿用显式客户选择与显式新建。
- `collectHistoricalSales(sheets)` 提取有效成交行。`lookupHistoricalPrice(sales, customerId, product)` 返回 `exact_match`、`unique_variant_match`、`ambiguous_variants` 或 `no_match`。`suggestDraftPrices(sales, customers)` 为缺价行返回同样的分流结果或 `unresolved_customer`。

服务入口位于 [server/memory.ts](../code/server/memory.ts)。`MemoryStore(pool)` 各方法的 `accountId` 由已认证会话提供。

- `customerDirectory(accountId)`、`listCustomerAliases(accountId)`、`resolveCustomerMention(accountId, rawInput)` 读取客户、简称或四档认人结果。
- `bindCustomerAlias(accountId, { requestId, alias, customerId, allowRebind?, allowCanonicalConflict? })` 返回保存的简称关联。`unbindCustomerAlias(accountId, { requestId, alias })` 返回 `{ removed }`，没有可解除的关联时为 `{ removed: null }`。
- `lookupHistoricalPrice(accountId, customerId, product)` 接收 `{ productName, brand?, spec?, unit }`，命中结果包含原文款式、整数分价格、趟 ID、单 ID 和首次出单时间。
- `suggestCustomerPrices(accountId, customers)` 接收带正式客户 ID 和整数分或空单价的客户明细集合。`suggestDraftPrices(accountId, draftId)` 与 `suggestDraftCustomers(accountId, draftId)` 读取工作区草稿，返回 `{ draftId, revision, suggestions }`。接入时可用草稿 ID、修订号与明细 ID 校验建议仍对应当前草稿。
