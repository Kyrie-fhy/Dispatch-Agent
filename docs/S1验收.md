# S1 验收步骤与记录

2026-11-15。代码和自动检查已完成，微信开发者工具及安卓设备体验待环境就绪后验收。

## 1. 标准操作

1. 执行 npm ci 和 npm run check，再按 README 导入微信项目。
2. 助手页点击重置演示，确认清空。应出现空客户及一条空货品。
3. 手动填客户 A、安井、水饺、500g、箱、2、82，或点击填入验收样例。
4. 预览后金额为 164.00 元。此时正式订单列表没有新增。
5. 返回修改，改为 80 元再预览，显示 160.00 元。再改回 82，重新预览为 164.00 元。
6. 确认生成，显示一张正式单。重复点击不得新增第二张。
7. 切换送货与对账页查看正式单，客户和订单金额一致。
8. 退出后重进，确认单仍在。开始下一张，出现新草稿，历史单仍在。
9. 添加第二条货品、修改和移除，核对预览合计；最后一条不能移除。

## 2. 异常

- 缺少单价、品牌或客户时阻止预览，提示具体字段。
- 单价 0.10 元、数量 3，结果为 0.30 元。零、负数、数量小数、超过两位小数的单价和不安全的大额值被拒绝。
- 修改后旧预览不可确认。已确认的草稿不能覆盖原单。
- 存储写入失败时显示错误，正式单数量不增加，重试成功后只有一张。
- 未知数据版本、错误金额或损坏结构不能自动重置覆盖。
