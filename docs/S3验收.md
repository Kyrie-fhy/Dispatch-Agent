# S3 对账与跨单收款验收

2026-11-16｜以下为开发和验收用例。以[开发 PRD 第 8 节](PRD.md#8-s3-对账与跨单收款)为操作依据。每个独立案例从指定初始数据开始，以免前一项的收款或更正影响账目。

## 1. 贯穿样例

从空白开始，按 [S2 基础输入](S2验收.md#1-基础输入与结果)录入 A/B/C，分别明确新建客户。在 A 对账详情补录一笔早于本趟的旧欠款 ¥60.00，来源写「旧手账 1」。全部送达 A，B 只送达 3 箱，B 的 3 袋和 C 整单确实未配送。分别核对三个客户单，不需要重复创建客户。

| 客户 | 订单金额 | 本次应收 | 期初本单实收 | 期初本单欠款 | 历史欠款 |
|---|---:|---:|---:|---:|---:|
| A | ¥164.00 | ¥164.00 | ¥0.00 | ¥164.00 | ¥60.00 |
| B | ¥300.00 | ¥240.00 | ¥0.00 | ¥240.00 | ¥0.00 |
| C | ¥75.00 | ¥0.00 | ¥0.00 | ¥0.00 | ¥0.00 |
| 整趟 | ¥539.00 | ¥404.00 | ¥0.00 | ¥404.00 | ¥60.00 |

## 2. 从正常入口操作

| 编号 | 操作 | 标准结果 |
|---|---|---|
| S3-01 | 从 B 开始对账，先故意遗漏箱明细的送达标记。打开待核对项，将箱补标为已送达，保留袋未配送，再确认。对 C 核实全部未配送。 | B 显示 ¥300.00 订单金额及 ¥240.00 应收，袋金额 ¥60.00 不计入。C 核对后本次应收 ¥0.00。三单都核对后，整趟得到第 1 节金额。取货仍为 5 箱、3 袋、1 箱。 |
| S3-02 | 在 A 的对账详情输入收到 ¥100.00，核对预览后取消一次，再预览并确认。快速重复确认同一预览。 | 取消时账目不变。保存仅一笔收款和两条分配，旧欠款 ¥60.00、本单 ¥40.00。A 历史欠款为零，本单实收 ¥40.00、欠 ¥124.00。整趟本单实收 ¥40.00、欠 ¥364.00，B/C 账目不变。 |
| S3-03 | 在助手开始下一趟，选择已有 A 开一张 ¥50.00 订单，确认，保持新单未配送。重进小程序，通过送货历史打开上一趟的 A，记录补款 ¥124.00。 | 下一趟确认后上一趟仍可查询，¥124.00 全部抵上一趟的 A。旧欠款 ¥60.00 和本单 ¥164.00 均已结清，两次收款的金额和去向可查。新单未配送、¥0.00 实收，切回当前趟可见历史欠款归零。 |
| S3-04 | 再开独立样例，在同一趟新建两位同名客户，分别核对。给其中一位补录旧欠款并记收款。下一趟从已有客户列表选择另一位。 | 列表可按客户编号与最近单据区分同名者。旧款和收款仅归第一位。另一位的旧欠款和累计实收仍为零，新单归所选客户。 |
| S3-05 | 为 A 准备同日早上和下午核对过的正式单，分别欠 ¥30.00、¥40.00。补录同日只有日期的旧欠 ¥50.00。将早上单由 1 箱 × ¥30.00 更正为 2 箱 × ¥15.00，再从下午单记录收款 ¥80.00。用同一原单时刻的独立副本检查并列规则。 | 正常顺序为早上 ¥30.00、下午 ¥40.00、日期项 ¥10.00，日期项余 ¥40.00。更正版本、操作入口和补录时间均不改变顺序。原单时刻相同或同日只有日期时，按持久化单据 ID 排序，重开结果一致。 |

## 3. 更正与异常

| 编号 | 初始条件与操作 | 标准结果 |
|---|---|---|
| S3-06 | 独立历史单应收 ¥200.00，已收 ¥200.00。从历史更正单价到 ¥220.00。先取消，再重新预览并重复确认。 | 取消时仍已结清。确认后只增加一版，应收 ¥220.00，实收 ¥200.00，欠 ¥20.00，原收款及分配可查。新版可导出，当前趟取货清单仍只显示当前趟。 |
| S3-07 | 独立副本把同类已结清单更正为 ¥180.00，再开启同客户新单，送达并核对，应收 ¥50.00。 | 旧单应收 ¥180.00、实收 ¥200.00、欠 ¥0.00、多收 ¥20.00。新单实收 ¥0.00、欠 ¥50.00。原分配不变，后续登记 ¥50.00 后新单结清，旧单多收仍为 ¥20.00。 |
| S3-08 | 在已核对的多明细单中，已送达行 ¥100.00，另有已送达行 ¥20.00，累计实收 ¥100.00。分别在独立副本将第一行替换为 ¥80.00 并选择已送达、替换后选择未配送、直接删除第一行。 | 替换须明确新行的配送状态；预览分别显示应收 ¥100.00、¥20.00、¥20.00，确认前原单和账目保持。确认后实收均为 ¥100.00，欠款均为零，多收分别 ¥0.00、¥80.00、¥80.00。新货品、旧货品移除以及取货数量差异与所选操作吻合。 |
| S3-09 | 在独立副本把已核对、已收 ¥82.00 的 1 箱改为未配送。先取消影响预览，再确认，然后补标已送达。另核对 S2 的 5 箱改为 3 箱场景。 | 取消保留原状态。改为未配送后应收 ¥0.00，实收 ¥82.00，多收 ¥82.00；补标恢复应收 ¥82.00、已结清。5 箱改 3 箱后原已送达标记保留，应收由 ¥410.00 变更为 ¥246.00。 |
| S3-10 | 在 A 尚欠 ¥124.00 时，尝试输入空值、0、负数、超过两位小数、超出安全整数的值及 ¥125.00。另对零欠款单记收款。 | 提示具体输入问题或当前最大可抵扣金额。全部尝试均无正式收款、分配及余额变化。输入 ¥124.00 后可正常预览。 |
| S3-11 | 得到收款预览后，从另一入口先完成同客户收款或更正。更正预览期间另完成一笔影响该单的收款。 | 两种旧预览都失效，提示按最新账目重新预览。刷新结果显示已发生的那笔变化，确认旧预览没有附加记录。 |
| S3-12 | 模拟旧欠款补录、收款、更正确认和送达修改分别写入失败，再恢复重试。另重复成功提交旧欠款，并新建同客户同日期、同金额和来源的补录草稿。 | 保存失败有可见反馈，正式单、收款、分配、配送及余额都保持原结果。恢复后每次操作只保存一次。同一笔补录不会重复增加旧欠款；不同来源的真实第二笔可另录。 |
| S3-13 | 分别从 S1 和 S2 存储恢复，覆盖同名未关联的历史单、旧版正式单及活动草稿。首次打开一张 S1 单进行对账。另模拟损坏或迁移写入失败。 | 原草稿、单据版本、配送状态和导图仍可查看。迁移不归并同名单、不推断收款；S1 状态先显示未记录，选择客户并明确核实各行后才参与分配。损坏或写入失败时保留原存储。 |
| S3-14 | 独立样例中给应收 ¥0.03 的单分别登记两笔 ¥0.01。每笔确认后记下提交结果，再重复第二笔的提交。 | 前两笔是独立收款，累计实收 ¥0.02，剩余欠款 ¥0.01。重复提交后记录数和金额保持。 |
