# S4 模拟助手验收

在微信开发者工具或测试号，从「助手」页进入。以下案例分开重置或开始新趟，避免不同案例共享价格与账目。图片、语音、查询样例均在界面中标明模拟。

| 编号 | 普通入口与操作 | 标准结果 |
|---|---|---|
| S4-01 | 在「输入示例」里准备 A 模拟历史价；发送图「A 微信截图」，再用语音示例补规格，编辑转写后发送；说「生成送货单」；选择 A 归属；说「这次按 82」 | 普通发送期间尚未预览。显示同客户同款的 ¥78/箱及来源日期；82 元覆盖样例价；预览 ¥164，取货页确认前无此单，确认后 2 箱。另用独立副本沿用历史价，预览 ¥156。 |
| S4-02 | 通过两张模拟图片和语音/文字录入 A/B/C。出单后切去取货、送货与对账。A 全送达；B 只标 3 箱送达；C 全送达。核对各单，为 A 补录旧欠款 ¥60。助手发送「客户 A 收到 100 元」，确认后再发「客户 A 收到 124 元」 | 订单 ¥539，取货为安井 5 箱、3 袋，三全 1 箱；B 订单 ¥300、应收 ¥240。A 首笔按 60/40 分配，本单欠 ¥124；补款结清，两笔记录。 |
| S4-03 | 先发缺规格的 A 图及另一条缺数量的材料；生成；先补 A 规格、单位 | 一次集中显示 A 规格以及另一条的数量；A 规格与单位明确前不建议历史单价；补齐后继续追问可用历史价。 |
| S4-04 | 重发同图或发相同订单文字；再选择补录。另用副本发送「客户 A 水饺 再要 3 箱」，生成后选「改成 3 箱」或「追加到 5 箱」 | 指出跳过的客户、货品和数量；明确补录可增加一条。数量未确认不预览，选择后原行变为 3 或 5。 |
| S4-05 | 已有 A 时发送使用「老 A」的材料；在集中问题中选择关联到已存在的 A。新趟再次输入相同别名，另对新建同名客户查价 | 只有明确选择才记录别名，后续按同一个客户 ID 匹配；给另一同名客户不套用该客户的价格或欠款。 |
| S4-06 | 对已送达且有收款的 A 发送「修改 客户 A 水饺 单价 110」；核对预览，返回或确认。在 B 两行都可能匹配时发「修改 客户 B 水饺 单价 81」。再输入不存在的客户 | A 的订单和应收 ¥164→¥220，已收 ¥164 不变，欠 ¥56；取消时保持原值。B 区分箱和袋，选择前无更新；无匹配提示指定原单。 |
| S4-07 | 发送「模拟失败」图片，点重试；发送未知句子，转手动补充；材料处理中手动改草稿或切换到新趟；模拟本地写入失败 | 失败保留材料，重试成功一次；未知内容保留原文。过期结果不写入更新后的草稿或另一趟，写入失败不显示成功。 |
| S4-08 | 快速连续发两批后立即发「生成送货单」。在收款、更正等操作中重复确认、制造预览过期 | 排队处理完再检查，采用同一草稿的最新有效状态。同一预览不重复生效，过期时保留正式账目。 |
