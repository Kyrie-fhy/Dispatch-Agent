## 本地会话接口

按 [S5 本地联调](S5本地联调.md)启动隔离测试库。服务端配置 `DISPATCH_WECHAT_APP_ID` 和 `DISPATCH_WECHAT_APP_SECRET` 后启用微信会话，启动日志显示「微信会话」。缺少其中一项时启动失败。两项都未设置时启动开发会话，继续使用测试身份 `a` 和 `b`。

`POST /v1/session/wechat` 接收 `{"code":"客户端 wx.login 返回的临时凭证"}`。响应为 201，只返回项目自己的 `token` 和 `expiresAt`。用 `Authorization: Bearer <token>` 请求 `/v1/workspace` 取得活动草稿和当前正式趟。`DELETE /v1/session` 撤销该凭证。服务按 AppID 和 OpenID 分开保存账本。启用微信会话后，开发登录入口关闭，原开发凭证无法使用。微信 `session_key` 无须保存。

凭证无效时，客户端重新调用 `wx.login` 并用新凭证登录。遇到微信频率限制或服务错误时，显示对应提示。接口仍使用本地监听。真实 HTTPS 接入、小程序端登录及切换账号时清除上一账号页面状态属于下一轮验证。

## 手机验收

1. A 登录后保存含可辨认客户名的草稿，并确认一趟订单。退出后重新进入，核对草稿 ID、修订号和正式单版本。
2. B 登录应进入自己的账本。确认 A 的草稿和正式单无法被 B 读取或修改。切换账号时，从上一账号发出的请求即使晚到也不得覆盖当前页面。
3. 下线会话后，用原凭证请求工作区应返回 401。重新取得微信凭证后应能恢复同一账号的记录。真机同时检查 HTTPS 请求没有依赖跳过域名校验。
4. 登录和恢复验收完成后，再验证材料上传中断恢复、材料归属和过期识别结果。
